# Frontend (planned)

The Blue-Team analyst dashboard is planned for **Stage 5** of the [roadmap](../docs/STAGE_BY_STAGE_MASTER_PLAN.md). This folder holds a placeholder until then.

Planned scope:

- React 18, Vite and Tailwind CSS console on port 5173
- Pages for the dashboard, alerts, incident investigation, analyst approval, N5 rules and metrics
- Live Evidence DAG view with the N1 path validation badge and the N4 ledger verification badge
- WebSocket stream of agent investigation traces from the backend

The Red-Team side already works today: see [`attack_simulator/`](../attack_simulator/).
